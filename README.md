# 📊 سیستم مانیتورینگ و سنجش کارایی Mirrorهای پکیج‌ها

این پروژه یک ابزار سبک و خودکار برای ارزیابی، تست سرعت (Latency) و پایداری میرورهای مختلف پکیج‌منیجرها (مانند `pip` و `npm`) است تا تیم‌های توسعه بتوانند در شرایط ناپایداری اینترنت، همواره به سریع‌ترین مخزن متصل شوند.

## ✨ ویژگی‌ها
- سنجش دقیق زمان پاسخ‌دهی (تأخیر بر حسب میلی‌ثانیه)
- شناسایی خودکار میرورهای قطع شده (Offline)
- قابلیت اجرای ادواری (Periodic) در بازه‌های زمانی مشخص
- مرتب‌سازی و معرفی خودکار سریع‌ترین میرور

## 🛠 نحوه نصب و راه‌اندازی (بازتولید سریع)
پروژه با استفاده از `Makefile` کاملاً خودکارسازی شده است. نیازی به نصب دستی وابستگی‌ها در سیستم‌عامل خود ندارید.

### پیش‌نیازها
- پایتون نسخه 3.8 یا بالاتر
- ابزار `make` (به صورت پیش‌فرض روی لینوکس و مک هست، برای ویندوز از Git Bash استفاده کنید)

### مراحل راه‌اندازی
۱. ابتدا مخزن را کلون کنید:
```bash
git clone [https://github.com/YOUR_USERNAME/mirror-monitor.git](https://github.com/YOUR_USERNAME/mirror-monitor.git)
cd mirror-monitor

۲. برای ساخت محیط ایزوله و نصب ابزارها کافیست دستور زیر را بزنید:
make
