# Package Mirror Monitor 🚀

یک ابزار مانیتورینگ سبک و سریع برای بررسی وضعیت و سرعت mirror های پکیج منیجر (مانند PyPI). این ابزار به توسعه‌دهندگان کمک می‌کند تا در زمان اختلالات اینترنت، سریع‌ترین و پایدارترین مخزن را پیدا کنند.

## امکانات
- تست سرعت و پایداری لیست مشخصی از mirror ها
- محاسبه دقیق زمان پاسخگویی (Latency)
- یافتن و معرفی سریع‌ترین mirror
- تولید گزارش به صورت فایل `JSON`
- قابلیت اجرای خودکار و ادواری

## پیش‌نیازها
- سیستم‌عامل لینوکس/مک (یا ویندوز با WSL)
- Python 3.x
- ابزار `Make`

## نصب و راه‌اندازی (Build)
برای ساخت و آماده‌سازی محیط برنامه، تنها کافیست در روت پروژه دستور زیر را اجرا کنید:
make setup
این دستور یک محیط مجازی (Virtual Environment) ساخته و کتابخانه‌های لازم را نصب می‌کند.

## نحوه استفاده
برای اجرای برنامه و گرفتن گزارش وضعیت mirror ها:
make run
پس از اجرا، خروجی در ترمینال چاپ شده و یک فایل به نام `report.json` شامل جزئیات در همان مسیر ساخته می‌شود.

## اجرای ادواری (اتوماتیک)
برای اینکه برنامه هر یک ساعت یک‌بار به صورت خودکار اجرا شود، دستور زیر را بزنید تا راهنمای تنظیم `crontab` به شما نمایش داده شود:
make schedule
